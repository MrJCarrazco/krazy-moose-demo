# Krazy Moose Subs — demo site

An **unsolicited, free concept website** for **Krazy Moose Subs**, 405 E Herning Ave, Wasilla, AK 99654 · (907) 357-8774.

Built by **Digital Consulting Studios** as a preview. **Not commissioned by, affiliated with, or endorsed by the business.**

- Single self-contained `index.html` — inline CSS + JS, no build step, no external assets besides Google Fonts and an OpenStreetMap embed.
- `<meta name="robots" content="noindex,nofollow">` so the preview never competes with the business's own listings.
- Zero fabricated content: no testimonials, no invented prices, no stock food photography, no awards or founding year. Everything unverified renders as a visible dashed placeholder. See `PLACEHOLDERS.md`.

If the owner wants it taken down, it comes down immediately.
